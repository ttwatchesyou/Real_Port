# โปรเจคที่ 8: ชุดฝึก PID ผ่านเว็บและ ESP32

## ภาพรวม

ชุดฝึกควบคุมมอเตอร์ด้วย PID Controller ผ่าน Next.js และ ESP32 MQTT

## ขอบเขตที่ระบุในเอกสารต้นฉบับ

- การควบคุมมอเตอร์ด้วย PID
- เว็บ Next.js
- ESP32 และ MQTT

## รายละเอียดฉบับขยาย

รายละเอียดส่วนนี้เป็นคำอธิบายหลักการและแนวทางพัฒนาเพิ่มเติมจากโจทย์ของโครงการ ไม่ใช่รายงานผลทดสอบหรือการยืนยันอุปกรณ์ที่ไม่ได้ระบุไว้ในต้นฉบับ

### โจทย์และจุดมุ่งหมาย

ทำให้การจูนมอเตอร์มองเห็นความสัมพันธ์ระหว่างค่าที่สั่ง ค่าที่อ่านกลับ และพารามิเตอร์ PID ผ่านเว็บที่เชื่อมกับ ESP32

### หลักการทำงาน

ชื่อโครงการระบุ Next.js, ESP32 และ MQTT จึงอธิบายการแยกหน้าจอ การแลกเปลี่ยนข้อความ และส่วนควบคุมมอเตอร์ได้ MQTT ใช้แนวคิด publish/subscribe ส่วนตำแหน่งที่รัน PID รุ่นมอเตอร์ และอุปกรณ์อ่านค่าจริงต้องยืนยันจากโค้ดกับวงจร

### แนวทางพัฒนาและทดลอง

1. กำหนดหน่วยของคำสั่งและค่าที่อ่านกลับให้ตรงกันก่อนเปรียบเทียบบนกราฟ
2. แยกข้อความคำสั่ง พารามิเตอร์ และข้อมูลตอบกลับ เพื่ออธิบายเส้นทาง MQTT
3. วางแผนเก็บกราฟหลายชุดเมื่อเปลี่ยนค่า PID โดยใช้เงื่อนไขเริ่มต้นเดียวกัน

### ประเด็นที่ควรตรวจสอบ

- เปรียบเทียบการพุ่งเกิน การแกว่ง เวลาที่เข้าค่า และความคลาดเคลื่อนคงค้างจากกราฟจริง
- แยกความหน่วงการสื่อสารออกจากรอบควบคุม และไม่ใช้กราฟจำลองแทนผลฮาร์ดแวร์

## ข้อมูลที่ควรแนบกับบันทึกชิ้นงานจริง

- รูปชิ้นงานแต่ละมุม พร้อมคำอธิบายหน้าที่ของส่วนประกอบ
- รุ่นอุปกรณ์และแบบวงจรหรือผังการเชื่อมต่อ
- โค้ดหรือโปรแกรมควบคุมที่ใช้จริง
- ขั้นตอนประกอบและปัญหาที่พบ พร้อมวิธีแก้
- วิธีทดสอบ เงื่อนไขการทดลอง และผลที่วัดได้
- บทบาทของผู้จัดทำและสถานะปัจจุบันของงาน
