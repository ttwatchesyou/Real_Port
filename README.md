# Theetawatch — Mechatronics & Robotics Portfolio

พอร์ตของ ธีร์ธวัช ตั้งตระกูลธนะกิจ / Theetawatch tangtakulltanakit ในธีม Modern Industrial Tech พร้อม responsive layout, บอร์ดแยกชิ้นส่วนตาม scroll แล้วประกอบกลับ, pointer parallax, circuit signals, project filters และรายละเอียดผลงาน รวม PID Lab แบบโต้ตอบ

## เริ่มใช้งาน

ใช้ Node.js 22 ขึ้นไป และ Yarn ผ่าน Corepack (เตรียมไว้แล้วในเครื่องนี้ เปิด terminal ใหม่เพื่อใช้งาน `yarn`)

หากย้ายไปเครื่องใหม่ ให้เปิดใช้ Yarn ด้วย `corepack enable` ก่อน โปรเจกต์กำหนดเวอร์ชัน Yarn ไว้ใน `package.json` และใช้ `yarn.lock` สำหรับล็อก dependencies ตามแนวทาง [Yarn Installation](https://yarnpkg.com/getting-started/install)

```sh
yarn install
yarn dev
```

เปิด http://localhost:3000

```sh
yarn typecheck
yarn build
yarn start
```

`yarn dev` เปิดโหมดพัฒนาพร้อมอัปเดตหน้าเมื่อแก้ไฟล์ ส่วน `yarn start` เปิดเว็บจากไฟล์ production จึงต้องรัน `yarn build` ก่อน ทั้งสองคำสั่งใช้พอร์ต 3000 ให้เลือกเปิดครั้งละโหมด

ตั้งค่าเป็น static export ไฟล์เว็บพร้อม deploy อยู่ใน `out/` หลัง build ใช้ static hosting ได้ ไม่ต้องมี backend ใช้ `yarn install --immutable` เมื่อต้องการติดตั้งตาม lockfile โดยไม่แก้ไขไฟล์ เช่นใน CI

## เพิ่มผลงานและเปลี่ยนข้อมูล

- `src/data/portfolio.ts`: เปลี่ยนข้อมูลส่วนตัว, อีเมล, ผลงาน, หมวดหมู่ และ tags
- `src/components/Portfolio.tsx`: โครงหน้าเว็บและ interaction
- `src/components/styles.ts`: styled-components ทั้งหมดและ responsive breakpoints
- `src/components/BoardAssembly.tsx`: ฉาก sticky แยก/ประกอบบอร์ด ควบคุมด้วย scroll ปุ่ม ไทม์ไลน์ หรือเล่นอัตโนมัติ และมีลิงก์ข้ามไปผลงาน
- `src/hooks/usePointerTilt.ts`: pointer parallax ผ่าน Web Animations API ไม่ใส่ inline style และหยุดทำงานเมื่อปิด motion
- `src/components/BoardModel.tsx` และ `src/lib/boardGeometry.ts`: โมเดลบอร์ด Three.js พร้อมวัสดุ แสง และรายละเอียดชิ้นส่วน
- `src/lib/appearance.ts`: พาเลตสีและช่วงเวลาของโหมดอัตโนมัติ
- `src/components/AppearanceProvider.tsx`: อ่านนาฬิกาเครื่องและบันทึกธีม
- `src/components/Visuals.tsx`: ภาพประกอบผลงานและ SVG สำรอง
- `src/components/pid/`: หน้า PID Lab, โมเดล Three.js, กราฟ และตัวควบคุม
- `src/lib/pid/engine.ts`: สมการฟิสิกส์และ PID แบบไม่ผูกกับ UI
- `src/lib/pid/plantGeometry.ts`: ชิ้นส่วนชุดทดลอง 3D วัสดุโลหะ พื้นผิว และสายไฟ
- `docs/pid-models.md`: สมมติฐาน สมการ และขอบเขตของแบบจำลอง
- `src/app/layout.tsx`: ชื่อเว็บและ metadata

ข้อมูลผลงานและบทบาทอิงจากข้อมูลที่เจ้าของพอร์ตให้มา ได้แก่ รางวัลชนะเลิศหุ่นยนต์ระดับชาติ, JINPAO Automation Contest, การฝึกเตรียม WorldSkills Thailand, งานไมโครคอนโทรลเลอร์, ชุดฝึก และ CAD/Simulation ไม่มีการแต่งปี ชื่อรายการแข่งขันระดับชาติ คะแนน หรือผลรางวัล WorldSkills เพิ่มเติม

หน้าเว็บผสมรูปจากอัลบั้มของเจ้าของผลงานกับกราฟิก SVG เคลื่อนไหวและโมเดล 3D พร้อมแสงเงา ผิวโลหะและลายวงจร ไม่มีการแสดงภาพที่เจนไว้ก่อนหน้าหรือภาพ stock (เก็บไฟล์เดิมไว้แต่ไม่ได้อ้างอิงในเว็บ) รูปที่ใช้ในเว็บอยู่ใน `public/images/my-work/` รายการภาพและคำบรรยายอยู่ใน `src/data/personalPhotos.ts` และข้อความสามภาษาใน `src/i18n/messages.ts`

หาก `profile.email` ว่าง แบบฟอร์มจะสร้างข้อความให้คัดลอกเท่านั้น เมื่อใส่อีเมลแล้วจะเปิดแอปอีเมลพร้อมร่างข้อความผ่าน mailto ไม่มีการส่งอีเมลจาก server

ใช้ Next.js App Router, TypeScript, Ant Design และ styled-components ไม่มี Tailwind และไม่มี style prop หรือ inline style ที่เขียนเอง ไลบรารี Ant Design อาจสร้าง inline style สำหรับการจัดตำแหน่งและ motion ภายในเอง

ลดเอฟเฟกต์ได้ด้วยปุ่ม MOTION ใน footer และรองรับ prefers-reduced-motion อัตโนมัติ เก็บค่าการเปิดปิดเอฟเฟกต์และธีมที่เลือกใน localStorage

การตั้งค่า SSR อ้างอิง [Next.js CSS-in-JS](https://nextjs.org/docs/app/guides/css-in-js) และ [Ant Design Next.js integration](https://ant.design/docs/react/use-with-next/)

## แอนิเมชันและ accessibility

บอร์ดเป็นโมเดล Three.js มี 105 กลุ่มชิ้นส่วนที่ขยับอิสระ แบ่งเป็น 5 ชั้น: PCB, ลายวงจร, ขาเชื่อมต่อ, อุปกรณ์อิเล็กทรอนิกส์ และฝาครอบ RF มีขา 44 ขา, อุปกรณ์ SMD 48 ตัว, รูทะลุพร้อมวงเคลือบโลหะ, ช่อง USB, ปุ่มกด และชิปใต้ฝาครอบ แสงสะท้อนวัสดุโลหะ เงา และมุมกล้อง perspective ช่วยให้เห็นความลึก ขาและอุปกรณ์กระจายออกทั้งแนวสูงและด้านข้าง หมุนรอบตัวเอง มีเส้นโยงตำแหน่ง ซูมดู เอียงตามเมาส์ และสลับโครงเส้นได้ โมเดลเป็นงานศึกษาเชิงภาพ ไม่ใช่แบบวงจรสำหรับผลิตจริง

ตำแหน่ง scroll ควบคุมการแยกและประกอบ รองรับการเลื่อนย้อน รวมการ render ด้วย requestAnimationFrame วาดเมื่อมีการเปลี่ยนแปลงและหยุดเมื่อพ้นหน้าจอ รวม geometry ตามวัสดุเพื่อลด draw calls จำกัดความละเอียดตาม pixel ratio และคืนทรัพยากรเมื่อ unmount หากเครื่องไม่รองรับ WebGL จะแสดงภาพ SVG ที่ยังแยกชั้นด้วยปุ่มได้แทน เมื่อใช้ prefers-reduced-motion ฉากยาวจะกลายเป็นส่วนปกติและยังเลือกดูชิ้นส่วนผ่านปุ่มได้

ทดสอบด้วย `yarn test:smoke` ครอบคลุม scroll ทั้งสองทิศ, pointer tilt, ปุ่มเลือกขั้นตอน, reduced motion, เมนูมือถือ, ฟอร์ม และขนาดหน้าจอ 320–1440 พิกเซล

## ธีมและแสงตามเวลา

เลือกจากปุ่มบนแถบเมนู: มืด / สว่างครีมพาสเทล / ตามเวลาจริง ค่าเริ่มต้นเป็นตามเวลาจริง ใช้นาฬิกาท้องถิ่นของอุปกรณ์ อัปเดตทุก 15 วินาทีและเมื่อกลับมาหน้าเว็บ ไล่พาเลตต่อเนื่องผ่านเช้า กลางวัน แสงเย็น อาทิตย์ตก พลบค่ำ และกลางคืน พร้อมปรับสีข้อความและ Ant Design ให้เข้าธีม ช่วงพระอาทิตย์ขึ้น/ตกเป็นตารางประมาณ ไม่ใช้ตำแหน่งที่ตั้งหรือข้อมูลดาราศาสตร์ ธีมที่เลือกคงอยู่เมื่อรีโหลดและซิงก์ระหว่างแท็บ

รัน `yarn test:appearance` สำหรับตรวจสีครบ 1,440 นาที, contrast ของข้อความ, การสลับธีมและจำค่า, นาฬิกาข้ามเที่ยงคืน, modal, แอนิเมชันหน้าการ์ด 19 ใบ พร้อมรูปจริงที่เก็บไว้ในรายละเอียด และ responsive ในทุกธีม ใช้ `CHROME_BIN` แบบเดียวกับ smoke test ได้

## สามภาษาและลูกเล่นเพิ่มเติม

เลือกไทย / 中文 (จีนตัวย่อ) / EN ได้จากเมนูด้านบน ภาษาเริ่มต้นเป็นไทยและบันทึกค่าที่เลือกไว้ แปลเนื้อหา ผลงาน รายละเอียดใน modal แบบฟอร์ม ข้อความตรวจสอบ และตัวควบคุมต่าง ๆ ชื่อเจ้าของและชื่อเทคโนโลยีคงเดิม ใช้ `src/i18n/messages.ts` แก้คำแปล โดย key คือข้อความต้นฉบับ และมี `th`, `en`, `zh` ครบ หากเพิ่มเนื้อหาใหม่ให้เพิ่มคำแปลในไฟล์นี้ด้วย

- `CircuitPlayground.tsx`: ทดลอง PWM เปิด/ปิดกำลัง ปรับความเร็ว กลับทิศมอเตอร์ และทริกเกอร์เซนเซอร์ ผลทั้งหมดเป็นการจำลอง
- `AmbientEffects.tsx`: แสงตามเคอร์เซอร์ แถบความคืบหน้าการอ่าน และปุ่มกลับด้านบน
- `Visuals.tsx`: บอร์ดวงจรวิ่ง แขนกลขยับ รถขนส่งเคลื่อนไหว และไฟสถานะ
- ภาพบนการ์ดตอบสนองเมาส์ มีแสงกวาดและแอนิเมชันเมื่อชี้ พร้อมการ์ดทักษะยกตัว

ปุ่มถอด–ประกอบและไทม์ไลน์ยึดค่าที่เลือกไว้ ไม่ถูกการเลื่อนอัตโนมัติของเบราว์เซอร์ทับ การเลื่อนด้วยล้อเมาส์ สัมผัส หรือปุ่มเลื่อนหน้าจะกลับไปควบคุมด้วย scroll เมื่อเปิดเอฟเฟกต์ กดเล่นเพื่อดูครบหนึ่งรอบ 9 วินาทีได้ เมื่อลดการเคลื่อนไหวยังเลือกดูภาพแต่ละขั้นได้

Smoke test ตรวจภาพ canvas ที่เปลี่ยนจริง รอโมเดลแยก/ประกอบครบ ตรวจปุ่ม ไทม์ไลน์ การเล่นอัตโนมัติ โครงเส้น signal lab ภาษาและการจำค่า รวม 15 คู่ภาษา/ขนาดหน้าจอ พร้อมโหมดลดการเคลื่อนไหวและ WebGL fallback

## ภาพถ่ายจริง

ใช้รูปจากอัลบั้ม `รูปWIL` ที่เจ้าของผลงานส่งมาแทนภาพอ้างอิงเดิมทั้งหมด คัด 14 รูปสำหรับแกลเลอรี และเก็บไว้ในรายละเอียดผลงานเดิม 6 ใบ โดยหน้าการ์ดเปลี่ยนเป็นแอนิเมชัน มีทั้งภาพถ่ายและเอกสารที่กำกับแยกกัน แบบแนวคิด JINPAO ระบุขั้นตอนนำไปขึ้นโมเดลต่อด้วย SolidWorks ตามข้อมูลที่เจ้าของผลงานยืนยัน แกลเลอรีรองรับภาพใหญ่ แถบรูปย่อ ปุ่ม ลูกศรคีย์บอร์ด และการปัดด้วยเมาส์/นิ้ว/ปากกา ภาพเสิร์ฟจากโปรเจกต์เป็น WebP พร้อม thumbnail และ srcSet จึงไม่ต้องเชื่อมต่อ Drive เมื่อเปิดพอร์ต รายการไฟล์และการจับคู่ภาพอยู่ใน `docs/personal-photos.md` ต้นฉบับทั้ง 50 รูปเก็บใน `assets/photo-originals/` ซึ่งไม่เข้า Git และไม่ได้เผยแพร่ในเว็บ

รัน `yarn test:photos` เพื่อตรวจรูปจากอัลบั้มครบทั้ง 14 รูป หน้าปกและคำบรรยาย การเลือกผ่านแถบรูปย่อ การปัดด้วยเมาส์และ touch จริงผ่าน browser, keyboard, สามภาษา และ modal บนมือถือ การซูมโมเดล PID ใช้กล้องที่เคลื่อนนุ่มนวลเมื่อเปิด motion และเปลี่ยนทันทีเมื่อผู้ใช้ลด motion ไฟบนบอร์ดกับแถบสัญญาณสะท้อน output และ saturation จากข้อมูลจำลองจริง

## สมุดผลงานจาก Drive

เปิด `/work` หรือปุ่ม “เปิดสมุดผลงาน 12 งาน” ในหน้าหลัก มี 12 งานจากชุด `projects_bundle_all_12` พร้อมหน้าแยก ค้นหาข้ามภาษา ตัวกรองหมวด ภาพประกอบ SVG เคลื่อนไหวที่หยุดได้ และดาวน์โหลด README ต้นฉบับ ทั้งหมดเพิ่มเป็นการ์ดในหน้าหลักด้วย รวมเป็น 19 งาน โดยยังคงผลงานและรูปเดิมไว้

อัปเดตจากโฟลเดอร์ชุดใหม่: เพิ่มรูปจริง 68 รูปในรายละเอียดทั้ง 12 งาน พร้อมคลิป MP4 13 คลิปจากวิดีโอ 8 ไฟล์ ภาพและวิดีโอเสิร์ฟจาก `public/` ในโปรเจกต์ ไม่ต้องโหลดผ่าน Drive ระหว่างใช้งาน มีภาพปกและเริ่มโหลดวิดีโอเมื่อกดเล่นเท่านั้น อัลบั้มใหญ่แสดง 6 รูปแรกและขยายได้ ภาพแอนิเมชันเดิมยังอยู่บนหน้าการ์ด งาน 1–11 มี README ระบุชื่อ ส่วนงาน 12 มีรายละเอียด Allen-Bradley / SE-TEK / KUKA จึงยังแยกคำอธิบายหลักการเพิ่มเติมออกจากผลทดสอบจริง ข้อมูล Mitsubishi FX5U ที่เจ้าของระบุแสดงในทักษะ PLC แยกจากงาน Allen-Bradley รายละเอียดแหล่งข้อมูลและการแก้ไขอยู่ใน `docs/project-notebook.md`

รัน `yarn test:work` เพื่อตรวจหน้าใหม่ทั้ง 12 หน้า ไฟล์เอกสารฉบับขยายและต้นฉบับ ตัวกรอง/ค้นหา ลิงก์หน้าหลัก สามภาษา สามธีม responsive และ touch/reduced motion

## PID Lab

กดการ์ด “PID Tuning Lab” ในผลงานเพื่อเปิด `/pid-lab` มีสาม workspace แยกกัน: มอเตอร์ DC พร้อม encoder, ลูกตุ้มกลับหัวที่สั่งแรงบิดตรงจุดหมุน และรถเข็นติดลูกตุ้ม แต่ละส่วนมีกราฟข้อมูลจำลองจริง การตั้งค่า PID, anti-windup, D filter, พารามิเตอร์ของ plant และ CSV ของข้อมูลที่เห็นบนกราฟ

สำหรับลูกตุ้มและรถเข็น ให้ตั้งค่า Initial angle และเป้าหมายจากช่องควบคุมตามปกติ จากนั้นกดเริ่มทดลองแล้วลากซ้าย–ขวาบนโมเดลเพื่อเติมแรงกระตุกจริงเข้าสู่ระบบ ทั้งเมาส์ นิ้ว และปากกาใช้ Pointer Events ชุดเดียวกัน และกดลูกศรซ้าย/ขวาเมื่อโฟกัสโมเดลได้ การลากไม่เปลี่ยน setpoint หรือวาร์ปตำแหน่ง จึงใช้ดูการฟื้นตัวของ PID บนกราฟได้ตรงไปตรงมา ช่องตัวเลขสามารถลบแล้วพิมพ์ใหม่ได้ โดยใช้คีย์บอร์ดตัวเลข/ทศนิยมบนอุปกรณ์สัมผัสและตรวจช่วงค่าเมื่อละโฟกัส

ธีมสว่างใช้ครีมเป็นพื้นหลักราว 60% ตามด้วยแซนด์/เอิร์ธโทน 30% และเซจ–พีชพาสเทล 10% สำหรับจุดเน้น ส่วนโหมดตามเวลาจริงไล่สีตามนาฬิกาเครื่องเหมือนเดิม

รัน `yarn test:pid-physics` เพื่อตรวจสมการและพฤติกรรมควบคุม และ `yarn test:pid-ui` เพื่อตรวจหน้า PID Lab, การลาก/คีย์บอร์ด, ช่องตัวเลข และคำสั่งความเร็วติดลบ

โมเดล PID Lab สร้างเป็นชุดทดลอง 3D รายละเอียดสูง มีฐาน tooling plate เจาะรู, น็อตหัวหกเหลี่ยมและแหวนรอง, ตัวเรือนมอเตอร์/คัปปลิง/ตลับลูกปืน, จาน encoder ช่องโปร่ง, ชุดลูกตุ้มพร้อมสเกลองศา, รางและล้อรถเข็น, บอร์ดควบคุมและสายไฟ ใช้พื้นผิวอลูมิเนียมขัดและสีพ่น พร้อมไฟหลัก/ไฟเติม/ไฟด้านหลังและเงาบนฐาน ปุ่มซูมชิ้นส่วนปรับกล้องจริงและกลับมาดูทั้งชุดได้ การเปลี่ยนความยาวก้านไม่ยืดรูปร่างตุ้มน้ำหนัก กล้องจัดเฟรมตามขนาดจอและความยาวก้าน รัน `yarn test:pid-models` เพื่อตรวจโมเดลทั้งสามชุดและเก็บภาพ desktop/mobile ใน `test-results/`

รายละเอียดใหม่ทุกงานมีโจทย์ หลักการ แนวทางพัฒนา/ทดลอง และประเด็นตรวจสอบครบสามภาษา โดยกำกับว่าเป็นการขยายแนวคิดจากข้อมูลที่มี ไม่สวมผลทดสอบหรือรุ่นอุปกรณ์ที่ยังไม่ได้ส่ง เอกสารดาวน์โหลดใน `public/documents/work/` เป็นฉบับขยาย ส่วน README ต้นฉบับแยกไว้ใน `public/documents/work/source/` ใช้ `yarn docs:work` เพื่อสร้างเอกสารจาก `src/data/workDetails.ts` หลังแก้เนื้อหา


รายละเอียดการนำเข้ารูป/วิดีโอและการบีบอัดอยู่ใน `docs/project-media.md` รัน `yarn test:media` เพื่อตรวจว่าไม่มีการโหลด MP4 ก่อนกดเล่น เล่นได้จริงด้วยเมาส์/สัมผัส/คีย์บอร์ด และขยายอัลบั้มครบทุกภาพได้
